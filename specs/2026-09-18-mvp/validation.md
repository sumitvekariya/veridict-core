- [x] `veridict attest --adapter python --sign key` on this repository's
      `HEAD` appends three note lines visible with
      `git notes --ref=veridict show HEAD`
- [x] `veridict verify HEAD` passes; editing one note line by hand makes it
      fail with a signature error naming the line
- [x] `veridict hook install` then a commit inside an agent session carries
